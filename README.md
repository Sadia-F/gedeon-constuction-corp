# Gedeon Construction Corp

Static website for Gedeon Construction Corp.

## Local preview

Open `index.html` in a browser. The site uses `style.css` and externally hosted Unsplash and Google Fonts assets.

## Deployment

The site is deployed automatically to GitHub Pages from the `main` branch using GitHub Actions.

Live site: https://sadia-f.github.io/gedeon-constuction-corp/
